# 动物大战

浏览器小游戏，当前主入口标题为“动物大战 v4.0”，项目说明将其定位为动物自动对战游戏。

## 入口
- 主页面：`index.html`
- 自动化测试目录：`test/`
- 另一版实现：`v2/`
- [预期 GitHub Pages 地址（待实际访问核验）](https://z15314102792-arch.github.io/animal-battle/)

## 本地查看
可直接打开 `index.html`。若浏览器限制某些功能，使用静态文件服务器访问。

## 清理说明
`test/` 和 `v2/` 可能用于回归测试或保留旧版实现，不能仅因目录名或文件较多就删除。
